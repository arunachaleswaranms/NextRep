# NextRep v1.0.0

First public GitHub release.

NextRep is a private, local-first habit app built around the **Winter
Arc**: a 92-day self-improvement challenge. Pick a few daily habits, show up
every day, earn XP, and climb from a frozen trail to a warm summit.

## Highlights

- **Rolling 92-Day Arc**: Day 1 is the day you press Start.
- **Seasonal Winter Arc**: 1 October – 31 December. Set it up in September
  or join mid-season; days before you joined don't count against you.
- **Custom habits**, alongside a catalogue of templates: done / not done,
  counts, minutes, or "before a time". Up to 12 habits per arc.
- **Sleep Before Target**: a morning check-in of last night's bedtime
  against your goal.
- **Minimum Day**: on a hard day, switch today to each habit's minimum and
  keep your streaks.
- **Perfect Days** with a bonus, streaks, XP and levels.
- **Journey**: your 92 days on a mountain path in six chapters.
- **15 achievements**, with celebrations.
- **Journal**: a 20-second nightly reflection (mood, one win, one thing to
  improve).
- **Insights** across your arcs: consistency, Perfect and Minimum Days,
  per-habit completion and moods.
- **Arc History**: every past arc with its summary, Journey and Journal.
- **Local reminders**: an optional daily nudge and an evening reflection
  prompt. Off by default.
- **Backup / restore**: export everything to a `.nextrep` file and restore
  it on the same or another device.

## Privacy

- Local-first: everything stays in the app's storage on your phone.
- No account, no sign-in.
- No analytics, telemetry, ads or tracking.
- No cloud sync and no NextRep servers.
- The Android release doesn't request the Internet permission, so the app
  can't send anything anywhere.

Backup files are **not encrypted** by NextRep. Keep them somewhere you
trust. Details: [PRIVACY.md](../../PRIVACY.md).

## Android installation

1. Download `NextRep-v1.0.0-android.apk` from this release.
2. Optional: check it against `NextRep-v1.0.0-android.apk.sha256`
   (`shasum -a 256 -c NextRep-v1.0.0-android.apk.sha256`).
3. Open the APK. If Android asks, allow your browser or file manager to
   install unknown apps. You can turn that permission off again afterwards.
4. Install, then open NextRep.

## Updating

Future releases are signed with the same key. Install a newer NextRep APK
over this one. **Don't uninstall first**: uninstalling deletes your data.

## Backup

Before a major upgrade, open **Data & Backup** (from Arc History) and tap
**Export Backup**. Save the `.nextrep` file somewhere safe off the phone.

## Compatibility

- Requires Android 7.0 (API 24) or newer, on arm64, armv7 or x86_64 devices.
- Tested on a physical OnePlus CPH2707 (Android 16) and on the Android 16
  (API 36) emulator. Other devices and Android versions are expected to
  work but weren't tested.
- iPhone: no build is published. The source builds for iOS (see the
  README), but there's no signed iOS release.
- Data: database schema v5. Backups are written as format 2; format 1 and 2
  backups can be restored.
